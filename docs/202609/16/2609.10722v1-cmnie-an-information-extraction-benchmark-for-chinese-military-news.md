## 摘要
从中文军事新闻中进行结构化抽取有助于情报分析、决策制定和知识库构建。然而，现有资源对该领域的联合信息抽取支持有限，尤其是在需要同时建模事件、事件论元、实体与关系的情况下。我们提出CMNIE，一个面向中文军事新闻的信息抽取基准。相较于仅进行文档级事件标注的军事领域资源，CMNIE在统一的领域模式（schema）下联合标注事件触发词、事件论元、命名实体和实体关系。该数据集包含来自公开中文军事新闻的13,000条实例，人工标注涵盖7种事件类型、10种论元角色、7种实体类型和8种关系类型。我们在共享测试集上评估了有监督的信息抽取模型、零样本大语言模型以及基于大语言模型微调的抽取方法。实验结果表明，CMNIE仍具挑战性，尤其是在关系抽取和事件—论元跨度的精确匹配方面；零样本大语言模型常能识别相关语义单元，但往往无法与金标准跨度边界精确对齐。CMNIE为研究特定领域中文新闻中的模式遵从性、精确跨度匹配以及联合结构化抽取提供了一个标准化的评测基准。

## Abstract
Structured extraction from Chinese military news supports intelligence analysis, decision-making, and knowledge base construction. However, existing resources provide limited support for joint informa?tion extraction in this domain, especially when events, event arguments, entities, and relations must be modeled together. We present CMNIE, an information extraction benchmark for Chinese military news. Extend?ing military-domain resources beyond document-level event annotations, CMNIE jointly annotates event triggers, event arguments, named enti?ties, and entity relations under a unified domain schema. The dataset contains 13,000 instances collected from public Chinese military news, with manual annotations for 7 event types, 10 argument roles, 7 entity types, and 8 relation types. We evaluate supervised IE models, zero-shot large language models, and fine-tuned LLM-based extraction methods on a shared test set. Experimental results show that CMNIE remains chal?lenging, especially for relation extraction and exact matching of event?argument spans; zero-shot LLMs often identify relevant semantic units but fail to match gold span boundaries exactly. CMNIE provides a stan?dardized benchmark for studying schema adherence, exact span match?ing, and joint structured extraction in specialized Chinese news.

# 一、核心问题与整体含义（研究动机与背景）

- 核心问题：如何在中文军事新闻这一信息密集、术语多样、关系隐含度高的专域中，联合且精确地抽取事件、事件论元、命名实体与实体关系，同时保证严格的模式（schema）遵从和精确的跨度边界匹配。
- 研究动机：
  - 军事新闻是情报分析、决策支持、知识库构建的重要来源，但现有数据集多偏通用领域或单一任务，缺乏对军事领域四层信息（事件、论元、实体、关系）的统一标注与联合评测。

- 整体含义：CMNIE 构建了一个覆盖面向军事新闻的联合信息抽取标准基准，提供统一领域 schema、规范化评测与多类方法对比，重点检验“模式遵从性”和“精确跨度匹配”，为专域联合抽取研究提供公共平台。

# 二、方法论：数据构建与评测方案（核心思想与技术要点）

- 核心思想：
  - 以统一的军事领域 schema 联合标注四层信息（事件、论元、实体、关系），并通过高标准的流程化审校与一致性度量，构建可复用、可对比的基准。
  - 在评测上同时提供严格的“精确匹配”与“宽松匹配”两种标准，以真实反映生成式/零样本模型在语义识别到边界对齐之间的性能差异。
- 数据源与样本构建：
  - 来源：新浪军事、凤凰军事、网易军事三大公开门户；时间跨度 2010-08 至 2022-02。
  - 爬取与清洗：去除重复、导航/HTML噪声、乱码等。
  - 候选检索：基于事件清单构建触发词词典，辅以 LLM 提议同义词后人工筛选，用于检索候选文本（仅用于召回，最终标注完全人工）。
  - 手工筛选标准：主题相关性、文本完整可读性、可标注性（偏向事件数量可控的实例）。
- 标注 schema（四层）：
  - 事件类型（7）：Experiment、Manoeuvre、Deploy、Accident、Indemnity、Support、Exhibit（在语料驱动下新增“Exhibit”以覆盖装备展示类新闻）。
  - 论元角色（10）：Subject、Equipment、Date、Location、Content、Area、Militaryforce、Result、Object、Materials。
  - 实体类型（7）：PER、TIME、GPE、EQU、ORG、LOC、FAC。
  - 关系类型（8）：Belong、Carry、Subordinate、Equal、Hostility、Develop、Cooperation、Fellow。
  - 设计原则：实体与事件论元分层标注；允许论元跨度包含更具体实体（嵌套）；Equal 关系用于统一长短名同指。
- 标注流程与质控：
  - 双阶段、多轮校对：第一阶段独立标注与分歧讨论迭代规则；第二阶段按统一标准全量修订，专家抽审与疑难仲裁。
  - 批次验收门槛：事件类型准确率、论元召回、实体召回、关系召回均≥95%方可通过。
  - 预裁决一致性（IAA）：在500例、10标注员上评估。事件有无/类型 Fleiss’ κ=0.9075；实体 F1=0.8688；触发词+类型 F1=0.8741；关系 F1=0.7266；论元 F1=0.7463。
- 数据统计与分割：
  - 规模：13,000 实例；包含事件的实例 6,997；事件触发词 6,997；论元 23,087；实体 97,508；关系 40,252。
  - 划分：Train/Dev/Test=8k/2k/3k，贪心保持事件标签分布一致；实例平均约 59.5 词。
  - 长尾特征：EQU/ORG 占实体主导；Belong/Subordinate/Equal 占关系主导；Manoeuvre 最常见事件；含空事件/空关系的实例占比显著，反映新闻异质性与层次不均衡。
- 评测指标与“宽松匹配”机制：
  - 事件四项：TI/TC/AI/AC（识别/分类）；严格匹配要求跨度与标签全对齐。
  - 宽松匹配（TI*/TC*/AI*/AC*）：允许预测跨度完全覆盖金标准且左右扩展不超过2个词；部分覆盖或截断不计；采用一对一最大匹配（匈牙利或等价二部图匹配思想）。
  - NER：实体类型+跨度同时匹配；RE：关系类型+两端实体跨度同时匹配。

# 六、主要结论与发现

- CMNIE 是一个挑战性强的专域联合抽取基准：
  - 关系抽取难度显著，RE F1 普遍低于 NER 与事件抽取。
  - 精确跨度匹配是零样本 LLM 的主要瓶颈，宽松与严格分数差距大。
- 不同范式的优势互补：
  - OneIE 在事件论元分类（AC）上最佳（53.9），表明显式跨度选择在论元精确匹配上仍具优势。
  - GoLLIE（Qwen2.5-7B 背骨）在触发分类（TC=70.3）与关系抽取（RE=50.2）上最佳，显示 schema 条件生成+对齐策略在关系抽取上更强。
  - NER 头部成绩（71.9、71.1、71.0）接近，说明实体识别已相对成熟但仍受领域术语边界影响。
- 零样本 LLM：
  - 最强零样本与最佳微调/监督相差显著（TC/AC/NER/RE 分别落后约 21、20、25、26 分），显示专域严格抽取对提示/对齐高度敏感。
  - 宽松评分显著提升（例如 DeepSeek-V3.1 TC* 71.3 vs TC 49.4），进一步确认“边界精确性”是关键挑战。

# 八、不足与局限

  - 仅覆盖中文与特定三家门户、特定时间段；跨语言/跨媒体的泛化能力有待验证。

- 应用与伦理：
